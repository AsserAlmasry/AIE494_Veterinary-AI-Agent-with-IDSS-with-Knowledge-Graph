## 🌟 Overview

The VETAI Intelligent Decision Support System (IDSS) is built to assist veterinarians and farm managers in diagnosing and treating cattle diseases. Traditional decision support relies on simple rules; VETAI orchestrates an ensemble of advanced models:
- **Identity Engine**: Identifies specific animals using a hybrid YOLO + ViT model.
- **Computer Vision**: Leverages MaxViT and Groq Llama 3.2 Vision to detect clinical signs from images.
- **Sensor Telemetry**: Analyzes real-time physiological data (Heart Rate, Temp) using Transformer-based time-series forecasting.
- **Knowledge Graph**: Queries a Neo4j graph database containing cattle history, disease progressions, and treatment protocols.
- **LLM Agent**: Uses Llama 3.3 70B to synthesize an expert-grade clinical report, citing retrieved PubMed literature and providing weight-based dosing.

## ✨ Key Features

- **Multi-Modal Diagnostics**: Drag-and-drop image analysis combined with manual vital signs input.
- **Weight-Based Dosing Engine**: Automatically calculates exact medication dosages based on the provided animal weight.
- **Biosecurity Safety Layers**: Automatically blocks treatment recommendations and issues alerts if Notifiable or Zoonotic diseases are suspected.
- **Live Interactive Agent**: A floating AI clinical agent available 24/7 to answer follow-up questions grounded entirely in your clinical case context.
- **Production Ready**: Fully containerized backend using Docker Compose.

## 🏗️ System Architecture

1. **Frontend (React/Vite)**: A sleek, modern dashboard utilizing TailwindCSS and Lucide-react for a premium user experience.
2. **Backend Engine (FastAPI)**: A highly asynchronous Python API handling the orchestration of ML models.
3. **Graph Database (Neo4j)**: Persistent storage for entity relationships between `(Cow)-[HAS_HISTORY]->(Disease)` and `(Disease)-[TREATED_BY]->(Protocol)`.
4. **Vector Knowledge Base**: ChromaDB integration for semantic retrieval of peer-reviewed animal science papers.

## 🚀 Getting Started

### Prerequisites
- [Docker](https://www.docker.com/) & Docker Compose
- [Node.js](https://nodejs.org/) (v16+)
- A Groq API Key (for LLM/Vision functionality)

### 1. Environment Setup
Clone the repository and set up your `.env` file in the root directory:
```bash
git clone https://github.com/AsserAlmasry/AIE494_Veterinary-AI-Agent-with-IDSS-with-Knowledge-Graph.git
cd AIE494_Veterinary-AI-Agent-with-IDSS-with-Knowledge-Graph

# Create environment file based on the example
cp .env.example .env
```
Ensure you paste your `GROQ_API_KEY` into the `.env` file.

### 2. Launch the Backend (Docker)
The backend and Neo4j database are fully containerized.
```bash
docker compose up --build -d
```
- The FastAPI backend will be available at: `http://localhost:8000/api/v1/docs`
- The Neo4j graph browser will be available at: `http://localhost:7474` (Default login: `neo4j` / `vetai_secret_123`)

### 3. Launch the Frontend
In a new terminal window, start the React application:
```bash
cd veterinary-frontend
npm install
npm run dev
```
Navigate to `http://localhost:5173` to view the VETAI Dashboard.

## 💻 Usage Guide

1. **Analyze a Case**: Upload an image of the cow. 
2. **Input Vitals**: Enter the animal's weight (e.g., `600` kg) and age (e.g., `3.5` years).
3. **Add Telemetry**: Provide the Body Temp (°C) and Heart Rate (bpm).
4. **Run Diagnosis**: The system will analyze the data, match the Cow ID via YOLO, query the Neo4j graph for past history, and generate a comprehensive MD report.
5. **Talk to Agent**: Click the chat widget in the bottom right to ask clinical follow-up questions like *"What is the withdrawal period for Meloxicam?"*
